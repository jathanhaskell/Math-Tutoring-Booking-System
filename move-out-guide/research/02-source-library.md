# Source Library

Every factual claim in the ebook traces to a row here. Cited claims in the
manuscript carry a bracket reference like `[S-12]`.

**Verification standard used:** each figure below came back from live web search
in September 2026 with a named publisher. Direct page fetching was blocked in
the build environment, so figures are as reported by the search index rather
than read off the source page.

**Before you sell this, spot-check every row marked ⚠️.** Those are the ones
where sources disagree or where a number moves fast.

## Citation Standard for the Ebook

1. Every dollar figure gets a bracket ref and appears in the Sources appendix.
2. Ranges are printed as ranges. Never collapse $3,000–$8,500 into "about $5,000."
3. Anything state-dependent (deposits, tenant rights, late fees) carries an
   explicit "verify your state" instruction. This is legal protection as much as
   accuracy.
4. Re-verify every ⚠️ row before each new edition. Rent and food figures go
   stale within 12 months and a stale number in a paid product generates refunds.
